💡 So funktioniert's:

Das Modell gibt für jede Probe eine Wahrscheinlichkeit aus. Der Schwellenwert bestimmt, ab welcher Wahrscheinlichkeit eine Probe als positiv klassifiziert wird.

Niedriger Schwellenwert: Mehr positive Vorhersagen → höherer Recall, aber mehr False Positives

Hoher Schwellenwert: Weniger positive Vorhersagen → höhere Precision, aber mehr False Negatives
