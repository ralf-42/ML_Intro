Aktuelle Transaktionen:

Was ist Support?

Support gibt an, wie häufig ein Item im Verhältnis zu allen Transaktionen vorkommt.

Was ist Confidence?

Confidence zeigt die Wahrscheinlichkeit, dass Item B gekauft wird, wenn Item A gekauft wurde.

Was ist Lift?

Lift zeigt, wie viel häufiger Items zusammen gekauft werden als bei einer zufälligen Verteilung zu erwarten wäre.
